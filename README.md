# CCAT Study Notes

A free, complete study guide for the Criteria Cognitive Aptitude Test (CCAT): how the 50-question, 15-minute test works, a clear method for every question type, 35 original practice items with full explanations, how scoring really works, a pacing plan built around the clock, and study plans for a week or a weekend. Written for anyone who has just been sent a CCAT link by an employer. Facts about the test come only from Criteria Corp's own pages, each one [cited](docs/sources.md).

Want to see where you stand first? Take the [free timed CCAT practice test on PrepClubs](https://prepclubs.com/free-practice-tests/ccat?utm_source=github&utm_medium=referral&utm_campaign=study-notes&utm_content=ccat) (50 questions, 15 minutes), or the shorter [10-minute diagnostic](docs/diagnostic.md) in this repo.

## Start here

1. **Find your weak spots.** Take the [10-minute diagnostic](docs/diagnostic.md). It has two items of each type and tells you where to start.
2. **Fix the weakest type first.** Open its guide below, learn the method and the traps, then do its 5 practice items.
3. **Learn the pace.** Read the [timing guide](docs/timing.md). On the CCAT, pacing moves your score more than anything else.
4. **Follow a plan.** Use the [7-day plan](docs/study-plans.md#7-day-plan), or the [2-day plan](docs/study-plans.md#2-day-plan) if your test link has already arrived.

## Quick facts

| | |
|---|---|
| Publisher | Criteria Corp |
| Questions | 50, multiple choice |
| Time | 15 minutes for the whole test (18 seconds a question) |
| Question types | Verbal, math and logic, spatial reasoning |
| Calculator | Not allowed |
| Penalty for wrong answers | None |
| Average result | 24 correct out of 50 |
| Finishing | Fewer than 1% of candidates answer all 50 |
| What the employer sees | Raw score and percentile |
| Pass mark | None published. Employers set their own score ranges for each role. |
| Languages | English (US), English (UK); other languages through Criteria's UCAT |

Sources: [Criteria: What to Expect on the CCAT](https://www.criteriacorp.com/candidates/ccat-prep) and [Criteria: CCAT product page](https://www.criteriacorp.com/assess/cognitive-aptitude/criteria-cognitive-aptitude-test-ccat), checked 24 November 2026.

## The five question types at a glance

Criteria names three types: verbal, math and logic, and spatial reasoning. These notes split math and logic into three guides, because each needs a different method.

| Type | You decide | Target time | Guide |
|---|---|---|---|
| Verbal | The opposite, the synonym, the analogy or the word that fits | 10 to 15 seconds | [Verbal](docs/sections/verbal.md) |
| Math word problems | Percentages, averages, rates, ratios, time, without a calculator | 25 to 35 seconds | [Math](docs/sections/math-word-problems.md) |
| Number and letter series | What comes next | 15 to 25 seconds | [Series](docs/sections/number-series.md) |
| Logic | True, false or uncertain; ordering; small puzzles | 15 to 40 seconds | [Logic](docs/sections/logic.md) |
| Spatial reasoning | Odd one out, next figure, grids, rotations | 15 to 30 seconds | [Spatial](docs/sections/spatial-reasoning.md) |

Target times are our guidance. Every type guide has the same parts: what it measures, how the questions look, a step-by-step method, the traps that cost points, timing advice, 5 original practice items with explanations, and a score table.

## How to use this repo

- **Read on GitHub.** Every page has links to the previous page, the next page and back to these contents, so you can read it start to finish like a book.
- **Test yourself honestly.** Answers are hidden under "Answers and explanations". Commit to an answer before you open them.
- **Time yourself.** The CCAT is a speed test. Each practice set has a target time in the [timing guide](docs/timing.md#practise-against-the-clock).
- **No calculator.** The real test does not allow one, so do not use one in practice either.
- **Read every explanation,** including for items you got right. Most explanations say why the tempting wrong option is wrong, which is where the learning is.
- **Keep a miss log.** For each miss, write down the habit that would have caught it. The [study plans](docs/study-plans.md#how-to-review-a-missed-item) show how.
- **Practise the full test.** The notes teach the methods. A full timed run, such as the [free one on PrepClubs](https://prepclubs.com/free-practice-tests/ccat?utm_source=github&utm_medium=referral&utm_campaign=study-notes&utm_content=ccat), teaches the pace.
- **Clone or fork it** if you want to annotate your own copy. The structure also works as a GitBook space: see [SUMMARY.md](SUMMARY.md).

## About the practice items

All 35 practice items (25 in the type guides and 10 in the diagnostic) are original, written for these notes. None are taken from the CCAT, from Criteria's materials or from any prep site. They follow the published question types so the methods you learn here transfer to the real test. Spatial items use text symbols so they display anywhere; the real test uses drawn figures.
